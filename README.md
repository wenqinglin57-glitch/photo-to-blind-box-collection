# Photo to Blind Box Collection

A reusable Codex skill for turning life photos into a coordinated six-item chibi 3D blind-box collection, a print-ready package, and six collectible cards.

## Workflow

- Two-person mode: three different two-person scene photos become six separate single-person figures.
- Single-person mode: six different scene photos become six separate figures.
- The six figures are approved before packaging begins.
- Only the package front uses transformed scene artwork; the other panels use coordinated solid colors.
- The collection includes six 50 × 80 mm portrait cards with text-free Gathered Scenes Zine backgrounds.

## Install

Copy this repository into your Codex skills directory as:

`~/.codex/skills/photo-to-blind-box-collection`

Then invoke it with:

`$photo-to-blind-box-collection`

## Contents

- `SKILL.md` — main routing and workflow instructions.
- `agents/openai.yaml` — skill metadata and default prompt.
- `references/` — intake, figure, packaging, and card production rules.
